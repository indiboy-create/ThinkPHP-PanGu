关于 PanGu

PanGu 是这套 ThinkPHP 工程矩阵的索引站。它本身是纯静态页面，使用 Layui 2.13.9 构建， 不依赖 PHP 运行时、数据库或前端构建工具，克隆后即可直接部署。

Structure

仓库如何组织

按交付形态分成四类，而不是简单按名称堆在一起。

think-* Composer 组件

以 youvision/think-* 包名发布，通过 composer require 引入 ThinkPHP 8 项目，覆盖基础架构、安全认证、数据处理、媒体文件、开放集成与开发体验。

LayuiAdmin-Iframe

独立的前端后台模板，原生 HTML + CSS + JavaScript，采用 Layui AMD 模块体系，提供 Vite 开发服务器与静态构建脚本。

glide-server

独立部署的按需缩略图服务，URL 参数驱动裁剪缩放，首次访问生成并缓存，不依赖 ThinkPHP 框架。

应用商店套件

think-static 负责 Composer 自动部署，think-store 负责发布包查询与同步，think-store-example 与 think-store-codeditor 是可直接安装的发布包实例。

Conventions

本站的整理原则

尽量让信息可验证、可操作，不替仓库编造不存在的能力。

以 README 为准

组件介绍、接口与配置项优先取自仓库 README 与 composer.json；只有名称、没有说明的仓库不强行包装成成熟组件。

区分组件与工程

Composer 包、前端模板、独立服务与发布包分别展示，避免把不同交付形态混在同一套安装说明里。

纯静态交付

所有页面都是静态 HTML，数据集中维护在 data.js，可直接托管到 GitHub Pages、对象存储或任意 Web 服务器。

指向源仓库

每个组件与项目都提供 GitHub 链接，版本、更新记录与问题讨论以源仓库为准。

环境基线

组件基线为 PHP >= 8.0 与 ThinkPHP 8；glide-server 要求 PHP >= 8.3，并需要 nginx 或 Apache 做请求转发。

安全提示

涉及模板编辑、数据库备份、支付与后台接口的组件，应在生产环境配置鉴权中间件、路径白名单与访问频率限制。

Tech

本站技术栈

Vite 仅用于开发服务器，生产构建由 Node 脚本输出静态文件；部署产物不依赖服务端运行。

Layui 2.13.9

导航、分页、弹层与基础样式，静态资源位于 src/component/layui，构建时原样保留。

原生 JavaScript

数据渲染、搜索筛选、URL 同步与复制命令均由一个通用脚本处理。

集中数据源

组件与项目数据维护在 data.js，页面按需读取并渲染，避免重复维护。

静态托管

把 public 目录作为站点根即可部署，不需要 PHP、数据库或 Node 环境。

数据与源码

本站源码与每个开源项目都可以在 GitHub 找到。如果发现描述不准确，欢迎直接提交 Issue 或 Pull Request。
